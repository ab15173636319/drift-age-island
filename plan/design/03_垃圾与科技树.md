# 03 · 垃圾与科技树

本作最核心的差异化系统。策划案第六节：「漂流垃圾是唯一的外部知识源」「垃圾同时是材料与知识」。

全局经济结论见 `00_总览与数值基准.md` 第四节，本文档定义清单与机制细节。

---

## 一、垃圾分级与刷新

### 刷新规则

| 参数 | 值 |
| --- | --- |
| 刷新周期 | 每现实日 1 次（游戏时钟 1:1） |
| 刷新数量 | 3–8 件，均匀分布，**均值 5.5 件/日** |
| 刷新位置 | 北沙滩 / 东礁石区 / 南沉船带（按区域解锁状态分配） |
| 拾取方式 | 点击地图上的垃圾图标，或行动「搜寻漂流物」 |
| 滞留时间 | 未拾取的垃圾保留 3 现实日，之后被潮水冲走 |

### 分级概率

| 分级 | 概率 | 日均件数 | 30 日累计 |
| --- | --- | --- | --- |
| 普通 | 80% | 4.40 | 132 |
| 稀有 | 17% | 0.94 | 28 |
| 关键 | 3% | 0.165 | 5 |

### 刷新概率修正

```
最终刷新数量 = base(3~8) × (1 + 瞭望塔加成) × (1 + 探索度加成) × 天气系数
```

| 修正源 | 效果 |
| --- | --- |
| 瞭望塔（建筑） | +20% |
| 满探索度（单区域 100%） | +15% |
| 季风天气 | ×2（+100%） |
| 雷暴天气 | 有概率劈出稀有垃圾（+1 件必为稀有以上） |

| 情境 | 日均 | 30 日 | 其中稀有 | 其中关键 |
| --- | --- | --- | --- | --- |
| 基础 | 5.5 | 165 | 0.94 | 0.165 |
| 瞭望塔 +20% | 6.6 | 198 | 1.12 | 0.20 |
| 瞭望塔 + 满探索度 | 7.6 | 228 | 1.29 | 0.23 |
| 季风期 | 11.0 | 330 | 1.87 | 0.33 |
| 全加成 | 15.2 | 455 | 2.58 | 0.46 |

（稀有列按 17% 折算，已含分级）

稀有垃圾中，**整本书与纸质图纸走独立的「稀有知识池」**（日均 0.15 件），不占用材料配额。

> **为什么要分池**：若知识载体与材料共用同一个稀有池，玩家会面临「拿整本书换知识点，还是留着做专精凭证」的零和取舍。核算结果是稀有材料集满时间从 116 日涨到 138 日（19.6 周），超出策划案设定的 2–3 个月叙事弧。分池后两条线可并行推进，稀有材料仍是后期最硬的闸门，但知识点不会来抢。

其余稀有垃圾（金属片、玻璃瓶、防水布、渔线、药品包装）是**专精凭证与改造链的唯一材料来源**。

## 三、关键件保底机制（必须实现）

### 问题

关键件日均仅 0.165 件。按「优惠券收集问题」计算，纯概率集齐 8 种：

```
期望件数 = 8 × (1/1 + 1/2 + ... + 1/8) = 21.7 件
期望天数 = 21.7 ÷ 0.165 = 132 现实日
```

132 天集齐关键件，而结局 A/C 都依赖关键件——这会让主线在第 4 个月还推不动，完全不可接受。

### 定稿方案：7 日保底

```
若连续 7 现实日未刷出任何关键件，
则第 8 日刷新时强制产出 1 件关键件（优先玩家尚未拥有的种类）。
计数器在获得任意关键件后归零。
```

| 指标 | 纯概率 | 加保底后 |
| --- | --- | --- |
| 集齐 8 种期望 | 132 日 | **≈36 日（5.1 周）** |
| 集齐上限 | 无上限 | **56 日（8 周）** |

保底后关键件集齐落在第 5–8 周，正好衔接策划案「第 2–4 周科技线展开 → 2–3 个月走向结局」的节奏。

**实现要点**：保底计数器写入存档（`keyItemPity` 字段），跨会话保留。「优先未拥有」确保后期保底不会浪费在重复件上。

## 七、垃圾图鉴

所有垃圾进入图鉴（`01_界面设计.md` 第八节），分三级页签。

| 完成度 | 奖励 |
| --- | --- |
| 普通全收集 | 心态上限 +5，称号「拾荒者」 |
| 稀有全收集 | 知识点 ×100，称号「考古学家」 |
| 关键全收集 | 解锁隐藏日记 + 成就「瓶中信」 |
| 垃圾图鉴 100% | 废料改造精通额外 +10% 产出，称号「垃圾文明」 |

图鉴每发现新物品时，日志流推送青色/紫色条目（见界面文档），并在右栏弹出 3 秒 toast。**关键件首次发现时全屏闪光 + 独立音效**，强化「垃圾即科技」的核心记忆点。
