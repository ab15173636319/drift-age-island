# 02 · 技能与产出

14 项技能，全部可挂机。每项定义：行动档、产出、解锁条件、满级精通。

全局经验曲线与档位基准见 `00_总览与数值基准.md`，本文档不重复。

本文档所有表格中的「时长」均为**基准耗时**。实际耗时随对应技能等级下降（**熟练度时长缩减**：每级 −0.3%，上限 −30%，详见 `00_总览与数值基准.md` 第三节），因此各技能「精通（Lv99）」中原本的「耗时 −30%」词条已并入该全局规则，不再单独列出。

**机制细节**：
- 陷阱是「布置」而非「持续采集」——每次行动消耗材料（藤索 ×1），布置后陷阱留存，之后每小时自动结算一次收获

**精通（Lv99）**：陷阱容量 +5，破坏率降为 3%，收获 +25%。

**精通（Lv99）**：所有改造配方材料 −20%（向下取整），专精凭证制作耗时减半，且 10% 概率返还知识点。

**叙事意义**：这个技能是「程序员靠文档解决问题」人设的玩法隐喻——把无序的垃圾（现实世界的混乱）拆解、归类、重组成有用的东西（工程能力）。它同时是材料线与知识线的交汇点。

### 11. 建造

建造技能的行动 = 建造/升级一座建筑。完整建筑清单与成本见 `05_建造与战斗.md`。

| 建造三级建筑 | T4 | 5.0s | 145 | 雨水收集棚、熏制架 |

| 维修建筑 | T2 | 4.0s | 26 | 风暴后修复，XP 为建造的 50% |

**特殊机制**：建造是**一次性行动**，不是循环挂机。点「建造」后进入一个长进度条（时长 = 材料件数 ÷ 产率），期间可离开界面，完成后通知。

**营地等级 = 全部建筑等级之和**（最高 54），直接决定：
- 离线时长上限 = 营地等级 + 1 小时（上限 24h）
- 生存消耗减免 = min(营地等级 × 2%, 40%)
- 可容纳自动化设施数 = 营地等级 ÷ 4（向下取整）

**精通（Lv99）**：建造材料 −15%，风暴对建筑的伤害 −50%。

**三个核心咬合点**（游戏节奏的发动机）：
1. **黏土 → 陶器 → 储水 → 离线上限**：让玩家为了挂机更久而去挖土
2. **营地等级 → 离线上限 → 消耗减免**：让玩家为了挂机更久而去盖房子
3. **垃圾 → 废料改造 → 专精凭证 → Lv51+**：让后期进度完全挂在核心特色系统上
