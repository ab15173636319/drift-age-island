# 07 · 成就系统

6 大类共 68 条。成就不是任务列表，**不做进度提示红点**（见 `01_界面设计.md` 第十节「不做的事」）——玩家是在回顾时发现自己达成了什么，而不是被清单驱动。

唯一的例外：成就「勤勉」与「一人成军」解锁并行槽位，这两条在技能界面有明确的进度显示，因为它们是功能性奖励。

```
┌──────────────────────────────────────────┐
│  🏆 成就                    已解锁 43/68    │
├──────────────────────────────────────────┤
│  [生存12][技能16][建造10][垃圾12][战斗8][叙事10][结局3] │
├──────────────────────────────────────────┤
│  🏆 第一把火              ✅ 第1天 解锁     │
│  🏆 连续 7 天             ✅ 第7天 解锁     │
│  🏆 十天不饿              🔒 7/10          │
│  🏆 ？？？                🔒 未公开         │
└──────────────────────────────────────────┘
```

**显示规则**：

| 状态 | 表现 |
| --- | --- |
| 已解锁 | 彩色图标 + 解锁日期 |
| 进行中（有明确计数） | 显示 `当前/目标`，如 `7/10` |
| 未解锁（无计数） | 显示成就名 + 🔒 |
| **隐藏成就** | 显示 `？？？` + 🔒，不透露任何信息 |

**隐藏成就共 6 条**：带病工作、撤退也是一种胜利、瓶中信、还有别人、三条路、十四星。这些是叙事或高难度成就，提前透露会破坏惊喜。

**称号**：玩家可在设置里选择一个已获得称号显示在顶栏。称号纯装饰，无数值效果。

## 九、奖励设计原则

| 原则 | 说明 |
| --- | --- |
| **只有正向奖励** | 成就奖励一律是增益（产出 +X%、耗时 −X%、心态上限 +5），没有「解锁 harder mode」这类增加负担的奖励 |
| **数值幅度克制** | 单条奖励幅度 ≤10%，全部集齐总增幅约 +60%。防止成就变成必刷的数值墙 |
| **功能性奖励只有 2 条** | 并行槽位（勤勉、一人成军）。这是唯一影响玩法结构的成就奖励 |
| **称号纯装饰** | 不带任何数值，避免「为了称号去刷」的强迫行为 |
| **不做成就点数** | 没有总分、没有排名。放置游戏的成就是回忆的索引，不是 KPI |
