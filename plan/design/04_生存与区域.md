# 04 · 生存数值与区域

策划案第五节的核心约束：「生存数值不是为了惩罚玩家，而是给离线收益提供上限与理由」。本文档所有 debuff 都配了明确的、可提前预防的解法。

---

## 一、六项生存数值

### 基础参数

| 数值 | 上限 | 基础消耗 | 恢复方式 | 归零后果 |
| --- | --- | --- | --- | --- |
| 饱食 | 100 | **3 / 游戏小时** | 进食（生食 8，熟食 12，大餐 40） | 体力下降、挂机效率减半 |
| 水分 | 100 | **4 / 游戏小时** | 饮水（每次 10）、雨水棚自动补给 | 强制中断挂机、进入脱水 |
| 体力 | 100 + 体能Lv×2 | 战斗/高风险探索消耗 | 睡眠（夜间自动，+8/h） | 无法进入高风险区域 |
| 体温 | 状态型 | — | 火塘、遮蔽所 | 中暑 / 感冒 debuff |
| 伤病 | 状态型 | — | 药品、卧床 | 挂机暂停 |
| 心态 | 100 | 见第三节 | 日记、新发现、建造 | <20 崩溃事件 |

**消耗速率设计依据**：水分 4/h 快于饱食 3/h（策划案：「水分消耗最快，热带设定」）。以 24 小时挂机计算，需水 96、需食 72——正好逼玩家在陶器（储水容量）和烹饪（食物保存）两条线上都投资。

### 每日总需求（含营地减免）

| 营地等级 | 减免 | 水分/日 | 食物/日 |
| --- | --- | --- | --- |
| Lv1 | 2% | 94 | 71 |
| Lv5 | 10% | 86 | 65 |
| Lv12 | 24% | 73 | 55 |
| Lv20 | 40%（上限） | 58 | 43 |

减免上限 40%。做不到 100%——否则生存系统会被建筑一次性买断，失去全程张力。

### 食物保存期

| 状态 | 保存期（游戏日） |
| --- | --- |
| 生鲜（鱼/兽肉/浆果） | 1–2 |
| 熟食 | 3 |
| 肉干 | 9 |
| 熏制（熏制架） | 27 |

腐烂的食物**不消失**，转为「腐坏食物」：食用后饱食 +4 但 30% 概率感染（寄生虫）。给玩家一个「实在没吃的」的兜底选项，而不是直接饿死。

## 二、debuff 清单与解法

**每个 debuff 必须有可提前预防的解法**——这是策划案第十三节的硬性要求。

| debuff | 触发 | 效果 | 持续 | 解法（预防） | 解法（治疗） |
| --- | --- | --- | --- | --- | --- |
| 脱水 | 水分归零 | **挂机强制中断**，心态 −8/h | 至饮水 | 雨水收集棚、储水器扩容 | 饮水 |
| 饥饿 | 饱食归零 | 效率 −50%，体力不恢复 | 至进食 | 熏制架（保存期 ×3）、药圃 | 进食熟食 |
| 中暑 | 正午户外连续 2h | 效率 −30%，水分消耗 ×1.5 | 4h | 简易遮蔽（Lv2+ 免疫） | 退烧药、阴凉处休息 |
| 失温 | 夜间无遮蔽 | 效率 −30%，心态 −5/h | 至天亮 | **简易遮蔽即免疫**（策划案原文） | 火塘、退烧药 |
| 感冒 | 失温未处理 3 日 | 效率 −20%，体力 −10/h | 5 日 | 遮蔽 + 火塘 | 退烧药 |
| 流血 | 荆棘带划伤（15%/次） | 体力恢复 −50% | 2h | 藤甲（免疫 40%） | 止血药、敷料 |
| 感染 | 流血未处理 6h | 效率 −40%，心态 −5/h | 3 日 | 及时止血 | 解毒剂 |
| 蛇毒 | 野蛇战斗失败 | 效率 −50%，HP 持续流失 | 6h | 骨矛以上装备（速杀） | 解毒剂 |
| 寄生虫 | 食用生水/腐坏食物 | 饱食消耗 ×1.5 | 7 日 | 煮沸消毒（科技树第一层） | 驱虫药 |
| 崩溃 | 心态 <20 | 随机损失 10%–30% 资源 | 一次性 | 见第三节 | 撰写日记、完成建造 |

**设计校验**：上表 11 个 debuff，其中 9 个可通过「建造某座建筑」提前完全免疫或大幅降低。只有「蛇毒」和「流血」属于战斗/采集的固有风险，且都有装备解法。符合「负面状态都有明确解法」的要求。

### 卧床机制

伤病等级 ≥2（感染、蛇毒、寄生虫）时，可选择「卧床休息」：
- 挂机完全暂停
- 恢复速度 ×3
- 心态 −3/h（躺着什么都不做的焦虑）
- 自动消耗库存食物与水

**卧床是玩家的选择，不是强制**。也可以选择带病挂机（效率打折）。给选择权，不给惩罚。

## 三、心态系统（本作特色）

### 数值规则

| 参数 | 值 |
| --- | --- |
| 上限 | 100（图鉴全收集可 +5） |
| 初始 | 60 |
| 自然回复 | 睡眠 +2/h；晴天 +0.5/h |
| 进食熟食 | +1 / 次 |

### 阈值

| 区间 | 效果 |
| --- | --- |
| **>80** | ✨ **心流** buff：全技能效率 +10% |
| 40–80 | 无效果 |
| 20–39 | 日志出现负面独白（纯叙事，无数值惩罚） |
| **<20** | ⚠ **崩溃事件**：随机损失 10%–30% 资源，心态重置为 30 |

### 心态事件表

| 事件 | 变化 |
| --- | --- |
| 撰写日记（主动行动） | **+4** |
| 首次进入新区域 | +9 |
| 新发现（图鉴/区域） | +6 |
| 完成建造 | +8 |
| 解锁回忆 | +7 |
| 击败 Boss | +12 |
| 救助搁浅海龟 | +10 |
| 信天翁来访 | +5 |
| 重复同一行动满 2 小时 | **−3** |
| 伤病在身 | −5 /h |
| 脱水状态 | −8 /h |
| 孤独夜（连续 3 游戏日无新发现） | −10 |
| 建筑被风暴摧毁 | −12 |
| 崩溃事件 | −25 |

### 「重复劳动 −3」的设计意图

这是本作最微妙的一条数值。放置游戏的本质就是重复劳动，如果重复不掉心态，心态系统就只剩单向增长，毫无张力；但如果掉太多，玩家会被自己的核心玩法惩罚。

**−3 / 2 小时**的强度是：连续挂机一整天（12h）掉 18 点，而写日记 +4、新发现 +6、完成建造 +8 能轻松补回来。也就是说，**纯挂机玩家会缓慢下滑，但任何主动行为都能逆转**。这精确表达了主题：逃离加班不是逃离劳动，而是让劳动重新变得有意义。

### 心流与崩溃的对称性

- 心流（>80）：+10% 效率，持续生效，日志出现积极独白
- 崩溃（<20）：损失资源，一次性，心态回升到 30

**崩溃后心态回到 30 而不是 0**，避免玩家陷入「崩溃 → 更焦虑 → 再崩溃」的死亡螺旋。放置游戏不应该有不可逆的失败状态。

## 四、区域系统

### 区域总表

| 区域 | 解锁条件 | 主要产出 | 风险 | 探索度上限 |
| --- | --- | --- | --- | --- |
| **北沙滩**（营地） | 初始 | 淡水（雨水）、贝壳、漂流垃圾 | 日晒、涨潮 | 100% |
| **东礁石区** | 体能/游泳 Lv5 | 鱼、蟹、海胆、玻璃碎片、盐 | **潮汐窗口**，退潮才能进 | 100% |
| **荆棘带** | 工具 Lv5 | 硬木、藤条、荆棘果 | 划伤（流血）、首次战斗 | 100% |
| **外林** | 荆棘带开辟通道 | 热带水果、木材、蘑菇、昆虫蛋白 | 蛇、蚊虫（疾病） | 100% |
| **南沉船带** | 第四章 + 潜水 Lv10 | 金属件、缆绳、电池、工具箱 | 体力消耗大、鲨鱼事件 | 100% |
| **内林深处** | 火把/照明 + 战斗 Lv15 | 稀有药材、大型猎物、山洞入口 | 野猪、巨蜥 | 100% |
| **山洞** | 内林探索 60% | 燧石、铁矿砂、黏土、蝙蝠粪、壁画 | 黑暗、缺氧 | 100% |
| **高地/火山口** | 建造瞭望塔 | 视野（全岛垃圾 +20%）、硫磺 | **雷暴禁入** | 100% |

### 探索度机制

```
每次区域行动 → 探索度 +0.4%
满探索需 250 次行动
```

| 探索度 | 本区域稀有物掉率 | 垃圾刷新加成 |
| --- | --- | --- |
| 0% | 8% | +0% |
| 25% | 11% | +3% |
| 50% | 14% | +7% |
| 75% | 17% | +11% |
| 100% | 20% | +15% |

**注意两套稀有率是分开的**：
- 探索度影响的是**本区域特产稀有物**（如内林的稀有药材、沉船带的高价值工具箱）
- 漂流垃圾的分级概率（普通 80% / 稀有 17% / 关键 3%）由刷新系统决定，探索度只影响**刷新数量**

探索度还解锁该区域的**专属日志**（每 25% 一条），是叙事内容的分发渠道。

### 潮汐窗口（东礁石区）

| 时段（现实本地时间） | 状态 |
| --- | --- |
| 00:00–04:00 | 退潮 ✅ 可进入 |
| 04:00–12:00 | 涨潮 ❌ 禁入 |
| 12:00–16:00 | 退潮 ✅ 可进入 |
| 16:00–24:00 | 涨潮 ❌ 禁入 |

每日 2 个窗口共 8 小时。非窗口期该区域行动置灰并显示倒计时「退潮还有 3h12m」。

**设计意图**：这是唯一一个「玩家必须调整自己作息来配合」的机制。它把现实时间变成了游戏内容——早上上班前摸一把、下午回来再摸一把，正好对应策划案「每天上线两次」的习惯养成目标。

### 高风险区域的体力门槛

| 区域 | 单次行动体力消耗 |
| --- | --- |
| 北沙滩 | 1 |
| 荆棘带 | 2 |
| 外林 | 2 |
| 东礁石区 | 3 |
| 内林深处 | 5 |
| 山洞 | 4（缺氧 ×1.5 = 6） |

## 五、生存循环的完整链条

```
水分消耗 4/h
    │
    ├─ 需要储水容量 ──▶ 陶器技能 ──▶ 需要黏土 ──▶ 采矿（山洞）
    │                     │
    │                     └─ 椰壳碗12 → 陶罐40 → 储水器96 → 陶缸120 → 蓄水池240
    │
    └─ 需要自动补给 ──▶ 雨水收集棚 ──▶ 需要防水布（稀有垃圾）+ 竹竿
                          │
                          └─ 天气依赖：雨天 +100% 淡水

食物消耗 3/h
    │
    ├─ 需要产量 ──▶ 采集 / 捕鱼 / 狩猎
    ├─ 需要效率 ──▶ 烹饪（熟食 ×1.5）──▶ 需要火种 ──▶ 伐木
    └─ 需要保存 ──▶ 熏制架（×3）──▶ 需要盐 ──▶ 捕鱼
                  └▶ 药圃（自动草药）

体力消耗
    │
    ├─ 恢复 ──▶ 睡眠（夜间自动 +8/h）──▶ 需要遮蔽所
    └─ 上限 ──▶ 体能与游泳等级

心态
    │
    ├─ 上涨 ──▶ 日记（主动）/ 新发现 / 建造 / 回忆解锁
    └─ 下跌 ──▶ 重复劳动 / 伤病 / 脱水 / 孤独夜
              └─ 全部可通过上述建筑与行为预防
```

**核心洞察**：生存数值的每一条消耗线，最终都指向一个具体的技能或建筑。玩家不是在被数值惩罚，而是在被数值**引导去体验全部内容**。这就是策划案说的「投资—回报节奏」。
