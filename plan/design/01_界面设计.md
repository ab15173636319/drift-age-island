# 01 · 界面设计

Melvor Idle 式纯界面驱动：没有角色跑动，只有面板、进度条、日志流。本文档定义全部界面结构与交互流。

---

## 一、整体布局

### 桌面端（≥1280px）：四栏

```
┌──────────────────────────────────────────────────────────────────┐

| 区域 | 宽度 | 内容 |
| --- | --- | --- |
| 顶栏 | 全宽 48px | 游戏时钟、天气、章节、心态值、设置 |
| 左栏 | 220px | 技能列表 + 主导航（地图/图鉴/日记/科技树/成就） |
| 中栏 | 弹性（min 520px） | 当前行动面板 + 快捷区 |
| 右栏 | 280px | 生存数值 + 当前增益 + 日志流 |

### 平板（768–1279px）：三栏

右栏折叠为底部抽屉，点击顶栏的生存数值图标上滑展开。日志流移到中栏行动面板下方的折叠区。

### 移动端（<768px）：单栏 + 底部 Tab

```
┌─────────────────────┐
│ 顶栏（压缩为单行）    │  第12天 07:40 ☁️ 😌74%
├─────────────────────┤
│                     │
│   当前面板内容       │  随底部 Tab 切换
│   （全屏）           │
│                     │
├─────────────────────┤
│ 🛠  ⚔  🗺  📖  📊   │  技能/战斗/地图/日志/状态
└─────────────────────┘
```

底部 5 个 Tab：

| Tab | 内容 |
| --- | --- |
| 🛠 技能 | 技能列表 + 行动面板（默认落地页） |
| ⚔ 战斗 | 敌人列表 + 配装 + 自动战斗开关 |
| 🗺 地图 | 区域列表 + 探索度 |
| 📖 日志 | 日志流 + 日记 + 图鉴 |
| 📊 状态 | 生存数值 + 增益 + 建造 + 科技树 |

**移动端优先级最高**（策划案：Web/移动端优先）。所有面板必须在 360px 宽度下可用，不出现横向滚动。

## 二、左栏：技能列表

### 列表项结构

```
┌──────────────────┐
│ 🪓  伐木     Lv31 │   图标 + 名称 + 等级
│ ████████░░  62%   │   当前等级进度条 + 百分比
│ ▶ 砍伐硬木  T4     │   当前挂机的行动 + 档位（未挂机显示「空闲」）
└──────────────────┘
```

### 状态表现

| 状态 | 表现 |
| --- | --- |
| 空闲 | 进度条下方灰字「空闲」，无动画 |
| 挂机中 | 显示当前行动名 + 档位，图标有缓慢呼吸动画（2s 周期） |
| 离线收益中 | 图标右上角显示 ⏳ 角标 |
| 未解锁 | 整项置灰，名称显示为「？？？」，下方显示解锁条件 |
| 可升级 | 等级数字变金色 + 轻微脉冲，提示玩家来点「升级」 |
| 已满级(99) | 等级右侧显示 ★，进度条替换为「精通：木材 +25%，5% 双倍」文字 |

### 排序规则

1. 挂机中的技能排最前
2. 可升级的排第二
3. 其余按解锁顺序（采集→伐木→采矿→捕鱼→狩猎→烹饪→石器→编织→陶器→废料改造→建造→医药→体能→研究）
4. 未解锁的排最后

**不做自定义排序**——固定顺序让玩家形成肌肉记忆，这是 Melvor 式界面的关键体验。

### 分类折叠

14 项技能分 4 组，每组可折叠：

| 分组 | 技能 |
| --- | --- |
| 采集类 | 采集、伐木、采矿、捕鱼、狩猎/陷阱 |
| 制作类 | 生火与烹饪、石器与工具、编织与绳索、陶器与容器、废料改造 |
| 生存类 | 建造、医药与草药、体能与游泳 |
| 知识类 | 记录与研究 |

组标题右侧显示组内汇总：「采集类 · 挂机中 2/5」。

## 三、中栏：行动面板

### 面板状态机

```
   [未选择]
      │ 点击技能
      ▼
   [目标选择] ──点击某个目标──▶ [准备中]
      ▲                          │ 材料够 + 体力够
      │ 返回                      ▼
      │                       [进行中] ◀──┐
      │                          │        │ 循环
      │ 点击停止                   ▼        │
      └──────────────────── [完成一次行动]──┘
                                 │
                        材料满 / 体力不足 / 水分耗尽
                                 ▼
                            [已暂停] ──补充资源──▶ [进行中]
```

### 各状态的界面

**[目标选择]** —— 卡片网格，每张卡片是一个可挂机的行动：

```
┌────────────────────┐  ┌────────────────────┐
│ 🫐 采集浆果         │  │ 🥜 采集坚果         │
│ T1 · 3.5s/次       │  │ T2 · 4.0s/次 🔒Lv5  │
│ 产出：浆果 ×1      │  │ 解锁条件：采集 Lv5   │
│ [开始挂机]          │  │ （置灰，不可点）     │
└────────────────────┘  └────────────────────┘
```

卡片信息固定 4 行：名称+图标、档位+时长、产出、按钮/锁。

**[进行中]** —— 核心界面，玩家 90% 时间在看这个：

```
┌───────────────────────────────────────┐
│ 🪓 伐木 · 砍伐硬木            T4 档    │
│                                       │
│ ████████████████████░░░░  3.1s / 5.0s │
│                                       │
│ 本次已获得：硬木 ×47                   │
│ 累计（本次会话）：硬木 ×1,204          │
│                                       │
│ 效率 3,600 件/小时                     │
│ 加成：心流+10%  金属斧×2  夜间-40%     │
│                                       │
│ 背包  硬木 12,004 / 上限 20,000        │
│ 体力  92/100                           │
│                                       │
│ [停止]  [切换目标]  [查看日志]          │
└───────────────────────────────────────┘
```

**关键设计点**：

- 进度条必须是**平滑动画**，不是跳变。这是「纯界面驱动」游戏唯一的动效预算，要花在刀刃上。
- 「加成」行必须**列出所有生效的修正项及其数值**，包括负面的（夜间-40%）。玩家要能算清楚自己的效率从哪来，这是数值透明度的底线。
- 背包接近上限（>90%）时，进度条边框转橙色并提示「背包将满，建造储物棚可扩容」。

**[已暂停]** —— 红色边框 + 明确原因：

```
┌───────────────────────────────────────┐
│ ⚠ 挂机已暂停                           │
│                                       │
│ 原因：水分耗尽（第 6 小时）             │
│                                       │
│ 解法：                                 │
│  · 建造雨水收集棚（需 竹竿×1500 陶罐×2）│
│  · 制作塑料瓶储水器（需 塑料瓶×3 藤条×5）│
│                                       │
│ [前往建造]  [前往制作]  [知道了]        │
└───────────────────────────────────────┘
```

**暂停界面必须给出可点击的解法按钮**，直接跳转到对应面板。策划案第十三节明确要求「所有负面状态都要有明确的、可提前预防的解法」——这个界面就是那条要求的前端实现。

## 四、右栏：状态栏

### 生存数值条

六项固定顺序，每项一行：图标 + 名称 + 数值条 + 数字。

```
🍖 饱食   ████████░░  86/100
💧 水分   ███████░░░  71/100   ⚠
⚡ 体力   █████████░  92/100
🌡 体温   [正常]
🩹 伤病   [无]
😌 心态   ███████░░░  74/100   ✨心流
```

**颜色规则**（全部界面统一）：

| 数值区间 | 颜色 | 表现 |
| --- | --- | --- |
| 70–100% | 绿 `#4CAF50` | 静态 |
| 40–69% | 黄 `#FFC107` | 静态 |
| 20–39% | 橙 `#FF9800` | 数字轻微脉冲 |
| 0–19% | 红 `#F44336` | 整行脉冲 + ⚠ 角标 |

体温与伤病是状态型（不是数值条），显示为标签：`[正常]` `[中暑]` `[失温]`；`[无]` `[流血]` `[感染]` `[蛇毒]` `[寄生虫]`。异常状态标签为红色，点击弹出详情（症状、剩余时间、解法）。

### 日志流

滚动文本，新条目从底部推入，最多保留 200 条（超出丢弃最旧的）。

**条目类型与样式**：

| 类型 | 颜色 | 前缀 | 示例 |
| --- | --- | --- | --- |
| 普通产出 | 灰 `#9E9E9E` | 时间 | `07:39 采集到浆果×3` |
| 资源消耗 | 灰 | 时间 | `07:35 水分 -4` |
| 等级提升 | 金 `#FFD700` | ⬆ | `⬆ 07:20 伐木升到 Lv32！` |
| 垃圾发现 | 青 `#00BCD4` | ✦ | `✦ 07:12 发现漂流物：玻璃瓶` |
| 稀有/关键 | 紫 `#9C27B0` | ★ | `★ 07:12 发现关键件：无线电模块！` |
| 剧情条目 | 白 + 斜体 | 📖 | `📖 07:01 你想起第一次提交代码的下午…` |
| 警告 | 红 `#F44336` | ⚠ | `⚠ 06:40 水分耗尽，挂机中断` |
| 成就 | 金 | 🏆 | `🏆 成就解锁：第一把火` |

**日志节流**：普通产出条目按 5 秒聚合一次（`07:39 采集到浆果×3` 而不是 3 条独立记录），避免刷屏。稀有及以上事件永不聚合。

点击任意日志条目展开详情（来源技能、精确时间戳、关联物品链接）。剧情条目点击直接跳转日记本对应页。

### 当前增益区

列出所有生效的 buff/debuff，每项一行：名称 + 效果 + 剩余时间（如适用）。

```
✨ 心流          全技能效率 +10%      （心态>80）
🍖 熟食          饱食效率 +15%
🌙 夜间          伐木 -40%   剩 3h12m
🩹 流血          体力恢复 -50% 剩 22m
```

点击展开该增益的来源与解除方式。

## 六、上线弹窗（离线结算）

玩家每次打开游戏的第一屏。**这是放置游戏最重要的界面，必须一眼看清得失。**

```
┌────────────────────────────────────────────┐
│  欢迎回来                                   │
│  离线时长：11 小时 24 分（营地上限 13h）      │
├────────────────────────────────────────────┤
│  ✅ 结算时长 11.4 小时（未被截断）            │
│  离线折算 ×0.6    生存系数 ×1.0              │
├────────────────────────────────────────────┤
│  获得                                       │
│  ─────────────────────────────              │
│  🪵 硬木            +24,624                 │
│  🫐 浆果             +8,208                 │
│  🪓 伐木 XP        +1,204,000  (Lv31→34)    │
│  🌿 采集 XP          +412,000  (Lv22→23)    │
│  ✦  漂流物              ×7  [查看]          │
│  ★  关键件：太阳能板碎片  [新!]              │
├────────────────────────────────────────────┤
│  消耗                                       │
│  ─────────────────────────────              │
│  💧 水分             −46                    │
│  🍖 食物             −34                    │
├────────────────────────────────────────────┤
│  期间事件                                   │
│  ─────────────────────────────              │
│  📖 07:12 你梦见母亲的来电…  [阅读]          │
│  🌧 03:00 下了一场雨，淡水 +80              │
│  🏆 成就解锁：连续挂机 10 小时               │
├────────────────────────────────────────────┤
│              [ 收下并继续 ]                  │
└────────────────────────────────────────────┘
```

### 弹窗设计规则

1. **固定四段式**：结算头 → 获得 → 消耗 → 期间事件。顺序永不变，玩家形成肌肉记忆。
2. **数字必须带符号**（+ / −）和千分位分隔。
3. **等级变化要显式标出**（`Lv31→34`），这是挂机游戏最主要的即时爽感。
4. **关键件用独立的 ★ 行 + `[新!]` 标记**，视觉上与普通掉落彻底区分——强化「垃圾即科技」的核心差异点。
5. **中途停止时**，第一段变为红色警告：

```
│  ⚠ 结算在第 6 小时中断                        │
│  原因：水分耗尽                               │
│  损失约 5.4 小时收益                          │
│  [建造雨水收集棚]  [制作储水器]                │
```

必须显示「损失了多少小时」的具体数字。模糊的「资源不足」不会驱动玩家去建造，具体的损失数字才会。

6. **超过 24 小时未登录**时，弹窗顶部加一句情绪化文案（从池中随机）：
   - 「岛上又过了 N 天。你在笔记本上划掉了 N 道刻痕。」
   - 「回来啦。火塘还温着。」
   - 「N 天没写日记了。笔尖有点干。」

这是「逃离加班」主题的低成本落点，不打断操作。

## 七、地图界面

```
┌──────────────────────────────────────────┐
│  🗺 全岛地图                    探索总进度 47% │
├──────────────────────────────────────────┤
│                                          │
│        ┌─── 高地/火山口 🔒 ───┐           │
│        │                      │          │
│   ┌─内林深处─┐                 │          │
│   │  探索 62% │                 │          │
│   └────┬─────┘                 │          │
│   ┌────┴─────┐   ┌─山洞 🔒─┐   │          │
│   │  外林     │   │         │   │          │
│   │  探索 88% │   └─────────┘   │          │
│   └────┬─────┘                 │          │
│   ┌────┴─────┐                 │          │
│   │ 荆棘带    │                 │          │
│   │ 探索 100% │                 │          │
│   └────┬─────┘                 │          │
│  ┌─────┴──────┐   ┌─南沉船带 🔒─┐         │
│  │ 北沙滩(营地) │   │            │         │
│  │ 探索 100%   │   └────────────┘         │
│  └────────────┘   ┌─东礁石区─┐            │

│                   └──────────┘            │

- 节点式布局（不做真实地形图，成本低且信息密度高），节点间连线表示通路
- 未解锁节点显示 🔒 + 解锁条件（点击展开）

- 节点底色反映当前状态：绿=可进入，黄=有风险（潮汐窗口/体力不足），红=禁入（雷暴）
- 点击节点展开详情面板：产出列表、风险、当前探索度、专属日志数、「前往」按钮

移动端地图缩放为纵向节点列表，保留全部信息。

## 八、图鉴 / 日记

### 图鉴（收集类）

四个分页签：**动植物** / **垃圾** / **装备与建筑** / **敌人**

```
┌──────────────────────────────────────────┐
│  📚 图鉴          [动植物][垃圾][装备][敌人] │
│                     完成度 143/312  46%    │
├──────────────────────────────────────────┤
│  🫐 浆果          ✅ 已发现  ×2,847        │
│     热带常见灌木果实，生食略涩，煮熟后…      │
│                                          │
│  🥥 椰子          ✅ 已发现  ×126          │
│     …                                    │
│                                          │
│  ❓ ？？？        🔒 未发现                │
│     提示：内林深处，夜间出没                │
└──────────────────────────────────────────┘
```

未发现项显示为 `？？？` + 一句提示（不给答案，给方向）。完成度每达 25%/50%/75%/100% 给奖励（见 `07_成就系统.md`）。

### 日记本

## 十、交互细节规范

### 反馈时长预算

策划案第一节「短决策长反馈：单次操作 3 秒」。落地为：

| 操作 | 目标响应时间 |
| --- | --- |
| 点击任何按钮 → 视觉反馈 | <100ms |
| 切换面板 | <200ms（含动画） |
| 开始挂机 → 进度条启动 | <100ms |
| 存档写入 | 异步，不阻塞 UI |

### 音效

极简，只有 4 个：

| 触发 | 音效 |
| --- | --- |
| 开始/停止挂机 | 轻「嗒」 |
| 等级提升 | 短促上行琶音 |
| 稀有/关键垃圾 | 清脆铃声 |
| 成就解锁 | 双音提示 |

默认开启，音量 40%。**产出、消耗、普通日志一律无音效**——放置游戏的音效如果跟着产出响，玩家 10 分钟就会静音。

### 无障碍

- 字体大小三档可调（小/中/大），大档下布局自动改为纵向堆叠
- 全部色彩状态同时有文字/图标标记（不只靠颜色传达信息）
- 进度条支持 `aria-valuenow`，屏幕阅读器可读
- 所有可点击区域最小 44×44px（移动端）

### 不做的事

| 不做 | 理由 |
| --- | --- |
| 强制新手引导遮罩 | 序章本身就是引导，不叠第二层 |
| 红点提示系统 | 放置游戏不需要制造焦虑，玩家自己会回来看 |
| 每日签到弹窗 | 违背「不做体力墙」的自我约束 |
| 任何付费入口 | 策划案第十节明确排除 |
| 联网排行榜 | MVP 阶段不做后端；且会诱发数值焦虑 |
