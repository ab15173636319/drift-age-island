# 10 · 新手引导状态机

序章（06 文档第一节）是纯剧情，不涉及系统教学。本文档定义**第一章「醒来」的逐步引导流程**——从沙滩醒来到全系统开放。

设计原则：
- **每步只教一件事**，不堆信息
- **强制行动后才解锁下一步**，保证玩家真的会了
- **所有引导文本都可跳过**（右上角「跳过引导」按钮），但首次不推荐

---

## 一、引导流程总览

```
序章结束（船体断裂黑屏）
  │
  ▼
G00 醒来（静态场景 + 四件随身物品展示）
  │
  ▼
G01 你需要水（强制：采集浆果 → 发现水坑 → 饮水）
  │
  ▼
G02 天快黑了（强制：建造简易遮蔽）
  │
  ▼
G03 生火（强制：生火 + 烹饪第一份熟食）
  │
  ▼
G04 左侧技能栏解锁（展示全部 14 项技能）
  │
  ▼
G05 右侧状态栏解锁（展示六项生存数值）
  │
  ▼
G06 日记解锁（撰写第一篇日记 → 心态 +5）
  │
  ▼
G07 图鉴解锁（第一只螃蟹/第一种植物入图鉴）
  │
  ▼
G08 漂流垃圾首次刷新（教学：点击拾取）
  │
  ▼
G09 离线结算教学（挂机 5 分钟 → 展示收益）
  │
  ▼
G10 引导结束（全系统开放，显示主线目标）
```

**总时长约 8-12 分钟**（不含序章 10 分钟）。

## 二、逐步定义

### G00 · 醒来

| 项目 | 内容 |
| --- | --- |
| 触发 | 序章结束自动进入 |
| 画面 | 沙滩静态背景，主角躺在沙滩上，右上角显示时间「第 1 天 08:00」 |
| 展示物品 | 四件随身物品以悬浮卡片形式出现：防水手机（电量 87%）、笔、笔记本、手表 |
| 引导文本 | 「你在沙滩上醒来。阳光刺眼。你摸了摸口袋——手机还在，笔和笔记本还在，手表停在 22:40。」 |
| 交互 | 点击任意位置继续 |
| 完成条件 | 点击 3 次（展示完四件物品） |
| 下一步 | 自动进入 G01 |

---

### G01 · 你需要水

| 项目 | 内容 |
| --- | --- |
| 教学目标 | 学会「采集行动」和「饮水」 |
| 引导文本 | 「你渴了。沙滩后面有一丛浆果，先采点果子垫垫。」 |
| 高亮区域 | 左侧技能栏 → 「采集」图标（唯一可点击） |
| 强制行动 | 捡拾浆果 ×3（自动完成进度条） |
| 完成后 | 弹出提示：「浆果只能解一半渴。那边有个雨水坑，去喝点水。」 |
| 高亮区域 | 中间面板 → 「饮水」按钮（新增） |
| 强制行动 | 饮水 ×1 |
| 完成后 | 水分条从 30 → 100，绿色闪烁 |
| 下一步 | 自动进入 G02 |

**设计意图**：第一次让玩家理解「采集 → 消耗 → 状态条变化」的核心循环。

## 三、跳过机制

- 每一步右上角都有「跳过引导」按钮
- 跳过后直接跳到 G10（全系统开放）
- 跳过后不可恢复（但可在设置里重新打开「新手引导」）
- **跳过不影响任何数值**——所有强制行动的产出都按正常计算

## 四、引导数据存档

```jsonc
{
  "tutorial": {
    "currentStep": "G05",        // 当前引导步骤
    "skipped": false,            // 是否跳过了引导
    "completedSteps": ["G00", "G01", "G02", "G03", "G04"],
    "stepTimestamps": {          // 每步完成的时间戳（用于平衡分析）
      "G00": 1760457600000,
      "G01": 1760457900000
    }
  }
}
```

**用途**：上线后统计每步的完成率和耗时，如果某一步流失率 > 20%，说明引导设计有问题，需要优化。

---

## 五、设计红线

1. **引导不能跳过核心循环**：G01-G03 必须强制完成，否则玩家不理解「采集 → 消耗 → 状态」的循环
2. **引导不能给太多信息**：G04-G07 只展示，不强制行动，避免信息过载
3. **离线结算是最后一步**：G09 必须在所有系统展示完之后，否则玩家不理解「离线收益从哪来」
4. **主线目标只给 3 个**：G10 只显示最近的 3 个目标，不展示全部 14 个建筑/8 个区域，避免吓退玩家
