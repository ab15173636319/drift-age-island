# 06 · 剧情与日记

叙事手法（策划案第二节）：全部通过「日记条目 + 手机旧消息截图 + 梦境闪回」碎片化呈现，**不打断挂机**。每升 10 级或完成一个里程碑解锁一条回忆。

---

## 一、序章（约 10 分钟，可加速）

序章是纯剧情，用 4x 时钟加速播放（见 `00_总览与数值基准.md` 第一节）。界面为全屏文本 + 状态条动画，无操作面板。

### 节拍表

| 拍 | 画面 | 文本 | 交互 |
| --- | --- | --- | --- |
| 1 | 黑底，绿色终端字体逐字打出 | `commit 4,817 / push / CI: FAILED` | 点击继续 |
| 2 | 同上，字体变慢 | `第 47 天。凌晨 3:12。` | 点击继续 |
| 3 | 淡入办公室窗外（城市夜景，静帧） | 「我看着那个红色的叉，忽然发现我已经不生气了。」 | 点击继续 |
| 4 | 一封信的形状淡入 | 「辞职信写了三遍。第一版太长，第二版太客气，第三版只有一句话。」 | 显示：`因个人原因，申请离职。` |
| 5 | 手机截图样式：银行 App | 余额：¥186,400.00 | 点击继续 |
| 6 | 游轮票的图片淡入 | 「四个月。远洋。不含返程日期变更费——因为我根本没打算改。」 | 点击继续 |
| 7 | **状态条动画**（核心节拍） | 见下 | 观看，可跳过 |
| 8 | 海平线，日出 | 「第 15 天。我终于睡够了、晒黑了、会游泳了。」 | 点击继续 |
| 9 | 状态条首次全绿（回放拍 7 的四条） | 「四个条，第一次全是绿的。我盯着看了很久。」 | 点击继续 |
| 10 | 夜色，风声音效渐强 | 「22:40。风变了。」 | 点击继续 |
| 11 | 屏幕剧烈晃动（CSS transform，无美术资源） | 「警报声不是电影里那种。是很平的、一直响的那种。」 | 点击继续 |
| 12 | 黑屏 | `船体断裂` | 自动进入第一章 |

### 拍 7 的状态条动画（序章的核心）

四个状态条从各种低值缓慢涨满，每个配一行字：

```
睡眠    ░░░░░░░░░░  →  ██████████   「第一次连续睡满 8 小时」
日晒    ░░░░░░░░░░  →  ██████████   「手臂开始脱皮，但是是健康的颜色」
游泳    ░░░░░░░░░░  →  ██████████   「今天游到了浮标」
信号    ██████████  →  ░░░░░░░░░░   「四格 → 一格 → 无。我关掉了它。」
```

**最后一条是全篇的题眼**：前三条涨满，第四条主动归零。玩家在 10 分钟内就能理解这个游戏在讲什么——不是逃离，是交换。

这四个条会在第一章以「饱食/水分/体力/心态」的形式重现，但**顺序和颜色完全一致**，让玩家潜意识里认出「又是这四个条」。

## 二、五章剧本节拍

### 第一章：醒来（沙滩）

| 触发 | 内容 |
| --- | --- |
| 开场 | 主角在沙滩醒来。随身四件物品以「物品栏」形式呈现：防水手机（电量 87%，无信号）、一支笔、一本笔记本、一块手表 |
| 教学 1 | 强制行动「捡拾浆果」→ 提示「你需要水」 |
| 教学 2 | 强制行动「饮水」（雨水坑）→ 提示「天快黑了，你需要遮蔽」 |
| 教学 3 | 强制建造「简易遮蔽」→ 教学结束，全系统开放 |
| 章节结束条件 | 建成简易遮蔽 + 火塘 |
| 解锁 | 日记本（可用「撰写日记」行动）、图鉴 |

**手机的四件物品是叙事道具，不是资源**：
- 防水手机：电量随时间缓慢下降（每游戏日 −0.5%），**太阳能充电板（科技树第四层）后永久供电**。电量决定能否查看旧消息——低电量时旧消息只能看到一半，这是玩家推进科技线的情绪动机。
- 一支笔 + 笔记本：日记系统的载体。
- 手表：显示游戏时钟，序章第 15 天的时间戳「22:40」会永久停在表盘上。

### 第二章：荆棘（森林外围）

| 触发 | 内容 |
| --- | --- |
| 开场 | 主角发现森林被荆棘灌木带封锁 |
| 需求 | 工具 Lv5 → 制作石斧 → 行动「开辟通道」 |
| 首次战斗 | 螃蟹（教学战，必胜）→ 野蛇（可能失败，教撤退机制） |
| Boss | **荆棘守护者**（二章末，需骨矛+藤甲，见 `05_建造与战斗.md`） |
| 章节结束条件 | 击败荆棘守护者 |
| 解锁 | 外林、狩猎/陷阱技能、编织与绳索技能 |

**荆棘守护者的真相**（策划案原文：「其实是一大群蜂群+野猪混战」）：战斗界面显示的敌人名字是「荆棘守护者」，但战斗日志里逐条打出的是「你被蜂群包围」「一头野猪从灌木里冲出来」。**击败后的日记会写「根本没有守护者。只是一群受惊的动物，和我一样。」**——这是本作第一次明确的叙事反转。

### 第三章：林中（果实与野兽）

| 触发 | 内容 |
| --- | --- |
| 内容 | 水果、淡水溪流、小动物、可食用昆虫 |
| 解锁 | 种植（药圃）、驯养（陷阱留存机制） |
| 心态线 | **第一次危机事件**（策划案第十一节「第 1 周」）：连续 3 游戏日无新发现 → 触发「孤独夜」，心态 −10 |
| 章节结束条件 | 药圃建成 + 心态首次跌到 40 以下后回升 |

**危机事件的设计**：这不是随机惩罚，而是**教学**。玩家会在此刻第一次意识到「心态」这个数值需要主动维护，然后学会用「撰写日记」这个行动。教学完成后，后续孤独夜事件的伤害减半（−5）。

### 第四章：残骸（科技线）

| 触发 | 内容 |
| --- | --- |
| 开场 | 退潮时露出游轮残骸（东礁石区的潮汐窗口首次显示沉船轮廓） |
| 解锁 | 南沉船带（潜水 Lv10）、废料改造技能、记录与研究技能 |
| 主线 | 垃圾 → 科技树，第一至三层 |
| 章节结束条件 | 获得首个关键件 + 解锁科技树第三层 |

**这一章是全游戏的转折点**：玩家从「生存」转向「重建文明」。所有此前的技能都变成了支撑科技线的资源管线。

### 第五章：信号（抉择）

| 触发 | 内容 |
| --- | --- |
| 前置 | 科技树第五层（通信）+ 至少 3 个关键件 |
| 三条路线同时开放 | 修复无线电 / 建造木筏 / 点燃巨型求救火堆 |
| 终 Boss | **飓风余波**（限时 20 回合生存战） |
| 章节结束条件 | 选定结局路线并完成对应建造 |

## 三、日记文本（前 10 条，可直接实装）

> 撰写规范：第一人称，短句，不用感叹号堆情绪。技术词汇要自然出现（主角是程序员），但不能变成术语炫耀。每条 80–160 字。

### 第 1 天 · 醒来

```
醒来的时候脸朝下，嘴里全是沙子。

我数的第一件事不是手指脚趾，是身上还有什么：手机、笔、笔记本、手表。
手机没信号，87% 的电。我第一反应是把它关机——然后又打开了。
关机之后我就真的一个人了。

笔记本第一页我写了日期。写完发现我不知道该写什么。
 forty-seven 天加班的时候，我每天有八千句话要说。
现在一句都没有。
```

### 第 1 天 · 火

```
钻木取火用了两个小时。

网上说十五分钟。网上还说这是"最简单的生存技能"。
我的手心磨破了两次，木头冒烟了四次，就是不起火。

第五次的时候我突然想到 CI。
不是那种"红了我很难过"的想到，是那种流程上的想到：
失败 → 看日志 → 改一个变量 → 再跑。
我把摩擦的角度调了大概十度。

火起来的时候我笑出声了。一个人笑出声，吓到了一只鸟。
```

### 第 3 天 · 遮蔽

```
下雨了。

我之前搭的那个东西——叫它遮蔽太抬举它了，就是几片叶子架在两根树枝上——
漏得像筛子。我在雨里站了大概二十分钟，然后开始重建。

这次我认真算了一下角度。
叶子要叠，不是铺。叠的方向要顺着水流，跟瓦片一样。

我蹲在自己的作品前面看了很久。
上一次这么看一个东西，是看我写的第一个能跑起来的程序。
那时候我也觉得，这是我做过的最好的东西。
```

### 第 6 天 · 荆棘

```
森林进不去。

外面看是树，走近了是墙。那种带刺的灌木，密得连手都伸不进去。
我试了一下，手背划了三道，血珠立刻出来。

以前遇到"进不去"，我的做法是找管理员开权限。
现在我需要一把斧头。

石头倒是很多。我在沙滩上挑了一下午，挑出三块边缘比较利的。
绑在木棍上的时候，藤条断了一次。第二次我把它拧成绳。

明天试试。
```

### 第 9 天 · 守护者

```
没有什么守护者。

我是说，我以为会有。荆棘带里面太安静了，安静得像是有什么东西在等着。
我拿矛进去的时候手心全是汗，脑子里已经开始想它会是什么样子。

结果是：一群蜂。加一头受惊的野猪。
它们比我更慌。

我被撞飞过一次，肩膀现在抬不起来。
但是路通了。

晚上我坐在火塘前面想，我好像一直在等一个 Boss。
加班的时候等，辞职的时候也等。
好像没有一个足够大的东西来挡我，我就没办法解释自己为什么停下来。

现在没有大东西了。只有荆棘，和蜂，和我自己。
```

### 第 12 天 · 水

```
水是最大的问题。

不是渴，是**算**。
我一天要喝多少，我的容器能装多少，下雨的频率是几天一次。
椰壳碗能装一点，但是不够。陶罐我试了，裂了两个。

后来我想通了：这不是采集问题，是容量问题。
我需要的不是更多水，是更大的桶。

我在笔记本上画了一张图。
画完发现，这是一张架构图。

我已经十二天没写代码了。
但是我好像还在写。
```

### 第 18 天 · 退潮

```
今天退潮退得特别远。

然后我看见了它。
船。或者说，船的一部分。侧躺在礁石那边，像一头搁浅的鲸。

我在那儿站了很长时间。
说不上是什么感觉。它是我来到这儿的原因，也是我离开这儿唯一的可能。
但是看着它的时候，我想的是：上面还有多少人的鞋没来得及穿。

回来的路上捡到一个玻璃瓶，里面是塑料和一点海水。
还有一个东西，金属的，扁扁的，边缘有电路板的纹路。

我把它揣在兜里，一路都在摸。
```

### 第 18 天 · 无线电模块

```
它是个无线电模块。

塑料壳裂了，但里面的板子是好的。我盯着看了很久——
上一次这么盯着一个东西看，是在看 CI 的红色叉。

不一样。

那次我想让它消失。
这次我想让它变绿。

我把它放在火塘边上，最干的地方。
然后我在笔记本上写了三行字：需要什么、缺什么、先做什么。

写完我自己愣了一下。
这是我四十天来第一次做需求拆解，而且不是为了任何人。
```

### 第 24 天 · 梦

```
梦见我妈打电话。

她问：吃饭了吗。
我说吃了。
她说：吃的什么。
我说不出来。

然后就醒了。火塘灭了一半，外面在下雨。

我坐起来，忽然很想给她打回去。
手机就在枕头边上（我用石头垫高了，怕潮），86% 的电，无信号。

我把旧消息翻出来看了一遍。
最后一条是她发的，两个月前：
「不用回，就是问问。」

我把它截图存进了笔记本。
```

### 第 30 天 · 一个月

```
一个月。

我在笔记本上划了三十道刻痕。划到第十五道的时候我发现自己在按周分组，
五道一划，跟排 sprint 一样。

这三十天我做了：一个能住的房子、一个火塘、两个陶罐、一把金属斧、
一片药圃、一个存雨水的东西。

我算了一下，如果按工时算，这些活儿在原公司大概值两个季度。
但那边我两个季度做的东西，现在一个都还在跑吗。

我不知道。我也不需要知道。

今天天气很好。我把无线电模块拿出来晒了晒。
还差蓄电池和铜线。
```

## 五、三个结局

### 结局 A · 归航（正结局）

| 项 | 内容 |
| --- | --- |
| 达成条件 | 船坞 Lv14 + 硬木 80,000 + 缆绳 4,000 + 金属件 6,000 + 五章装备（改造钢管+复合护甲）+ 科技树第七层「远洋航行」+ 击败飓风余波 |

### 结局 B · 长居（治愈向）

| 项 | 内容 |
| --- | --- |
| 达成条件 | 心态值 100 + 全部 14 座建筑建成且满级（基地等级 54）+ 科技树第七层「家园营造」 |
| 关键件需求 | 无强制（但太阳能充电板会解锁额外日记） |

| 特殊 | 心态必须**在终幕那一刻**是 100，不是曾经到过 100。这是全游戏唯一一个对心态有硬性峰值要求的场合 |

### 结局 C · 失联（隐藏结局）

| 项 | 内容 |
| --- | --- |
| 达成条件 | 无线电修复件完成 + 信号发射器建成 + **收集全部漂流瓶日记**（16 条，散落在各区域探索度里程碑）+ 科技树第七层「永恒广播」 |
| 关键件需求 | 无线电模块、蓄电池、铜线圈（3/8） |
| 预计达成 | 第 12–20 周（漂流瓶受探索度限制，是最慢的收集线） |
| 终幕 | 无线电修好了。他发出信号，等了三天，无人应答。然后他把发射器改成循环广播，内容是那 16 条别人的日记。镜头停在发射器的指示灯上，一直闪。最后一行：**「他选择留下广播。」** |
| 隐藏提示 | 玩家必须在图鉴里发现「漂流瓶」这个条目（不显示在任务列表），才会知道有这条线。第一次捡到漂流瓶时，日记里会出现一句没有主语的话：「还有人写过。」 |

### 结局选择机制

科技树第七层三个节点互斥。选定后进入 7 现实日的「准备期」，期间可改选（消耗 100 知识点）。准备期结束后锁定，触发终章 Boss（结局 A/B）或直接进入终幕（结局 C）。

**通关后**：解锁「新游戏+」，保留图鉴与成就，重置技能与建筑，垃圾刷新率 +25%，日记可继续写。
